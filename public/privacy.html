포트폴리오 — 개인정보·안전 안내

개인이 만들어 무료로 공개한 주식 시세·포트폴리오 화면입니다(웹·맥·윈도우·안드로이드 앱 공통). 시행일 2026-10-23.

한 줄 요약
  • 내 보유 종목·거래 기록은 내 기기 안에만 저장됩니다. 운영자 서버로 보내지 않습니다.
  • 증권사 계좌·비밀번호·공동인증서를 받지도, 묻지도 않습니다. 매매 기능도 없습니다.
  • 광고·방문 분석·추적 도구를 쓰지 않습니다.
  • 구글 로그인은 켠 경우에만, 내 구글 드라이브의 이 앱 전용 숨김 공간에만 저장합니다.

1. 어떤 정보를 어디에 두나요

보유 종목·수량·평단·거래 기록·그룹·설정지금 쓰는 브라우저(또는 앱)의 저장 공간(IndexedDB·localStorage)에만 둡니다. 다른 기기와 나누려면 아래 구글 드라이브 동기화나 파일 백업을 직접 켜야 합니다.
구글 드라이브 동기화 (선택)로그인한 본인 드라이브의 앱 전용 숨김 공간(drive.appdata)에만 저장합니다. 이 권한으로는 드라이브의 다른 파일을 볼 수도 바꿀 수도 없습니다. 운영자는 그 파일에 접근할 수 없습니다.
파일 백업 (선택)설정 → 파일로 저장하기 를 누르면 내 컴퓨터에 .json 파일로 내려받습니다. 어디에도 올리지 않습니다.

2. 시세는 어떻게 가져오나요

  • 토스증권·네이버 금융·야후 파이낸스·다음 금융·한국경제 등 누구나 볼 수 있는 공개 시세를 가져옵니다. 요청에는 종목 코드만 담기고, 내 보유 수량·평단은 담기지 않습니다.
  • 앱(맥·윈도우·안드로이드)·크롬 확장: 내 기기가 그 사이트에 직접 요청합니다. 중간 서버를 거치지 않습니다.
  • 웹 브라우저(중계 서버): 브라우저 보안 규칙(CORS) 때문에 중계 서버가 공개 시세 주소를 대신 불러옵니다. 중계 서버는 시세를 전달만 하고 저장하지 않습니다. 서버를 운영하는 클라우드 회사(Deno·Cloudflare·Render 등)는 일반적인 접속 기록(IP·시각)을 남길 수 있습니다. 직접 중계 서버를 만들어 등록하면 그 서버만 씁니다.

3. 밖으로 나가는 것 — 직접 누를 때만

  • 질문하기: Padlet(외부 게시판)이 열립니다. 쓰는 내용은 Padlet 에 저장됩니다.
  • 후원하기: 카카오페이 송금 화면으로 이동합니다.
  • 🔍AI: 종목 이름·현재가로 만든 질문을 구글 검색(AI 모드)으로 엽니다.
  • 토스·네이버 링크: 해당 사이트로 이동합니다.

4. 앱은 안전한가요

  • 소스 코드가 전부 공개되어 있습니다 — github.com/hanjungwoo3/portfolio-web
  • 맥·윈도우 앱은 GitHub 서버가 공개 코드로 자동 빌드한 파일입니다 — 빌드 기록: Actions → desktop. 누가 손으로 만든 파일이 아닙니다.
  • 앱이 하는 일은 이 사이트를 띄우고 공개 시세를 직접 받아오는 것뿐입니다. 파일·사진·연락처에 손대지 않고, 컴퓨터 설정을 바꾸지 않습니다.
  • 앱 안 업데이트는 운영자 서명을 확인한 파일만 설치합니다. 서명이 맞지 않으면 설치하지 않습니다.

처음 실행할 때 경고가 뜨는 이유 — 애플·마이크로소프트의 유료 개발자 인증서(연 수십만 원)를 쓰지 않아서입니다. 위험하다는 뜻이 아니라 "누가 만든지 운영체제가 확인하지 못했다"는 뜻입니다. 처음 한 번만 이렇게 여세요.

  • 맥: 압축을 풀고 포트폴리오.app 을 우클릭 → 열기 → 열기. "손상되었기 때문에 열 수 없습니다" 가 뜨면 터미널에서 xattr -cr ~/Downloads/포트폴리오.app (앱이 있는 위치로) 한 번.
  • 윈도우: "Windows의 PC 보호" 창에서 추가 정보 → 실행.
  • 안드로이드: 설치할 때 "출처를 알 수 없는 앱" 허용이 필요합니다.

5. 지우는 방법

  • 기기에 저장된 것: 브라우저의 사이트 데이터 지우기, 또는 앱 삭제.
  • 구글 드라이브 연결: 설정 → 로그아웃. 권한까지 끊으려면 구글 계정 → 서드파티 연결에서 이 앱을 삭제하세요. 숨김 공간 파일은 구글 드라이브 → ⚙️ 설정 → 앱 관리 → 이 앱의 숨겨진 앱 데이터 삭제로 지웁니다.
