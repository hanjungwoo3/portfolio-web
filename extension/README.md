# 🧩 포트폴리오 시세 프록시 (크롬 확장)

앱을 **팝업으로 띄우고**, 시세 요청을 **브라우저가 직접** 보냅니다.
프록시 워커도, 로컬 서버도 필요 없습니다.

## 왜 쓰나

토스는 **egress IP 풀 단위**로 요청을 막습니다. Cloudflare·Netlify 같은 클라우드
프록시는 나가는 IP를 전 세계 고객이 공유해서, 내 호출량이 0이어도 그 풀이 붐비면
같이 막힙니다. 실측에서 개인 Cloudflare 워커 2개가 **동시에** `400 + 빈 본문`을 받았고,
지수(`c-chart`)는 통과하는데 종목 시세(`stock-prices`)만 막혀 **보유 그룹만 통째로 비었습니다.**

이 확장은 요청을 **내 브라우저에서** 보냅니다. 가정용 IP라 그 차단에 걸리지 않고,
호출 한도도 없습니다.

| | 공개 프록시 | 개인 워커 | 로컬 서버 | **확장** |
|---|---|---|---|---|
| 설치 | 없음 | 배포 1회 | Node + 터미널 | **확장 1회** |
| 실행 유지 | — | — | 터미널 켜둬야 | **브라우저만** |
| 토스 400 | 잦음 | 잦음(같은 풀) | 드묾 | **드묾** |
| 호출 한도 | 공유 | 100k/일 | 없음 | **없음** |

## 설치 (개발자 모드)

1. 이 저장소를 받고(또는 `extension` 폴더만 내려받아) 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → `extension` 폴더 선택
5. 툴바의 퍼즐 아이콘 → **포트폴리오 시세 프록시** 를 고정(📌)

엣지도 같은 방법으로 됩니다(`edge://extensions`).

> 개발자 모드로 설치하면 크롬을 켤 때마다
> "개발자 모드 확장 프로그램을 사용 중지하세요" 안내가 뜹니다. 무시해도 동작합니다.

## 쓰는 법

툴바 아이콘을 누르면 앱이 팝업으로 뜹니다. 위쪽 막대에 상태가 나옵니다.

| 표시 | 뜻 |
|---|---|
| ● 프록시 사용 중 (내 브라우저) | 정상 |
| ● 프록시 미연결 | 확장이 아직 안 붙음 — 새로고침하거나 재설치 |

팝업이 좁으면 **새 탭에서 열기 ↗** 를 누르세요. 탭에서 열어도 확장이 그대로 붙어
프록시는 계속 동작합니다.

## 기존 데이터·설정은 그대로입니다

팝업은 앱을 `https://hanjungwoo3.github.io/portfolio-web/` 주소로 띄웁니다.
**오리진이 웹에서 쓰던 것과 같아서** 보유·거래 기록(IndexedDB), 설정, 구글 로그인
상태를 그대로 공유합니다. 옮길 것이 없습니다.

확장을 지워도 앱은 웹에서 평소처럼 동작합니다.

## 동작

```
앱(iframe 또는 탭)
   │ window.postMessage
콘텐트 스크립트 (content.js)
   │ chrome.runtime.sendMessage
서비스워커 (background.js)
   │ fetch  ← 여기가 내 IP
토스 · 네이버 · yasun · investing · TradingView
```

- **호스트 화이트리스트** — 위 목록만. 그 외 도메인은 거부합니다.
- **헤더 재작성** — 토스는 `Origin`이 `tossinvest.com`이 아니면 `403`입니다
  (실측: Origin 없음 `200` / `chrome-extension://` `403` / `tossinvest.com` `200`).
  `Origin`·`Referer`는 `fetch()`로 못 바꾸는 금지 헤더라 `declarativeNetRequest`로 갈아끼웁니다.
  이 규칙은 **`tabIds: [-1]`** 조건이 붙어 **확장이 보낸 요청에만** 적용됩니다 —
  사용자가 브라우저로 토스·네이버를 직접 볼 때는 아무 영향이 없습니다.
- **바이트 그대로 전달** — 네이버 자금동향은 EUC-KR이라 텍스트로 옮기면 깨집니다.
  응답을 base64로 넘기고 디코딩은 앱이 합니다.

## Yahoo 는 확장으로 안 갑니다

Yahoo는 반대로 **가정용 IP를 `429`로 막습니다**(`Edge: Too Many Requests`).
그래서 앱이 Yahoo 요청만 클라우드 프록시로 보냅니다. 자동이라 설정할 것은 없습니다.

## 안 되는 것

- **모바일** — 크롬 안드로이드는 확장을 지원하지 않습니다. 모바일은 웹으로 쓰세요.
- **사파리** — 이 형식 그대로는 안 됩니다.
