# 🧩 포트폴리오 확장 프로그램

두 가지를 합니다.

1. **시세를 내 브라우저가 직접 가져옵니다** — 종목이 빈 칸으로 나오는 문제가 없어집니다.
2. **툴바 아이콘으로 앱을 바로 엽니다** — 브라우저 옆에 붙는 패널로 열려서
   주소를 칠 필요가 없고, 다른 탭을 보는 중에도 계속 띄워둘 수 있습니다.

크롬·엣지에서 됩니다. (사파리·휴대폰은 안 됩니다)

---

# 설치 방법

## 1단계 — 파일 받기

아래 파일을 내려받고 **압축을 풉니다.**

📦 [portfolio-proxy-extension.zip 받기](https://github.com/hanjungwoo3/portfolio-web/releases/latest)

압축을 풀면 `manifest.json` 등이 들어 있는 폴더가 생깁니다. **이 폴더를 기억해 두세요.**

> 압축을 꼭 풀어야 합니다. zip 파일 그대로는 등록되지 않습니다.

## 2단계 — 확장 관리 화면 열기

크롬 주소창에 아래를 입력하고 엔터:

```
chrome://extensions
```

엣지는 `edge://extensions` 입니다.

## 3단계 — 개발자 모드 켜기

화면 **오른쪽 위**의 `개발자 모드` 스위치를 켭니다.

켜면 위쪽에 버튼 몇 개가 새로 나타납니다.

## 4단계 — 폴더 등록

방금 나타난 **`압축해제된 확장 프로그램을 로드합니다`** 버튼을 누르고,
1단계에서 압축을 푼 **폴더를 선택**합니다.

> 폴더 안의 파일이 아니라 **폴더 자체**를 선택해야 합니다.

## 5단계 — 툴바에 고정

주소창 오른쪽의 **퍼즐 조각 아이콘(🧩)** 을 누르고,
**포트폴리오 시세 프록시** 옆의 **압정(📌)** 을 눌러 고정합니다.

**끝났습니다.** 툴바에 생긴 아이콘을 누르면 브라우저 오른쪽에 앱이 열립니다.

패널 **왼쪽 경계선을 끌면 넓이가 조절**됩니다. 충분히 넓히면 표가 있는
데스크톱 화면으로 바뀌고, 좁히면 휴대폰처럼 나옵니다.

# 자주 묻는 것

**화면이 좁아요**
패널 **왼쪽 경계선을 마우스로 끌면** 넓어집니다. 넓히면 데스크톱 표 화면으로 바뀝니다.
아주 넓게 보려면 위쪽 **`새 탭 ↗`** 으로 여세요.

**꼭 패널로 열어야 하나요?**
아니요. 평소처럼 북마크나 주소로 들어가셔도 확장이 똑같이 동작합니다.
패널은 주소 치기 귀찮을 때 쓰는 편의 기능입니다.

**기존 데이터가 사라지나요?**
아니요. 웹에서 쓰던 주소를 그대로 띄우기 때문에 보유·거래 기록, 설정,
구글 로그인 상태가 전부 그대로입니다. 확장을 지워도 앱은 평소대로 동작합니다.

**크롬을 켤 때마다 "개발자 모드 확장을 사용 중지하세요" 라고 떠요**
개발자 모드로 설치하면 크롬이 매번 물어봅니다. **무시하셔도 됩니다.**
(웹스토어에 등록하면 없어지지만 아직 등록 전입니다)

**프록시 설정은 어떻게 하나요?**
그대로 두시면 됩니다. 확장이 처리하지 못하는 일부(차트·과거 시세·미국 지수)는
기존 프록시를 계속 사용합니다.

# 문제 해결

**● 프록시 미연결 이라고 나올 때**

1. `chrome://extensions` 에서 확장이 **사용 중(파란 스위치)** 인지 확인
2. 앱 화면에서 새로고침(`Ctrl+R` / `Cmd+R`)
3. 그래도 안 되면 확장을 지우고 4단계부터 다시

**시세가 안 나올 때**

`chrome://extensions` 에서 이 확장의 **`서비스 워커`** 링크를 누르면 개발자 도구가 열립니다.
빨간 오류 메시지가 있으면 그 내용을 알려주세요.

# 기술 메모

## 왜 필요한가

토스는 **egress IP 풀 단위**로 요청을 막습니다. Cloudflare·Netlify 같은 클라우드
프록시는 나가는 IP를 전 세계 고객이 공유해서, 내 호출량이 0이어도 그 풀이 붐비면
같이 막힙니다. 실측에서 개인 Cloudflare 워커 2개가 **동시에** `400 + 빈 본문`을 받았고,
지수(`c-chart`)는 통과하는데 종목 시세(`stock-prices`)만 막혀 **보유 그룹만 통째로 비었습니다.**

확장은 요청을 **내 브라우저에서** 보냅니다. 가정용 IP라 그 차단에 걸리지 않고,
호출 한도도 없습니다. 기존 [내 PC 로컬 프록시](../workers/local-proxy/README.md)를
대체합니다 — Node 설치도, 터미널도, 서버를 켜두는 것도 필요 없습니다.

## 동작

```
앱(사이드 패널 iframe 또는 일반 탭)
   │ window.postMessage
콘텐트 스크립트 (content.js)
   │ chrome.runtime.sendMessage
서비스워커 (background.js)
   │ fetch  ← 여기가 내 IP
토스 · 네이버 · yasun · investing · TradingView
```

- **호스트 화이트리스트** — 위 목록만. 그 외 도메인은 거부합니다.
- **헤더 재작성** — 토스는 `Origin`이 `tossinvest.com`이 아니면 `403`입니다
  (실측: Origin 없음 `200` / `chrome-extension://` `403` / `tossinvest.com` `200`).
  `Origin`·`Referer`는 `fetch()`로 못 바꾸는 금지 헤더라 `declarativeNetRequest`로 갈아끼웁니다.
  이 규칙에는 **`tabIds: [-1]`** 조건이 붙어 **확장이 보낸 요청에만** 적용됩니다 —
  사용자가 브라우저로 토스·네이버를 직접 볼 때는 아무 영향이 없습니다.
- **바이트 그대로 전달** — 네이버 자금동향은 EUC-KR이라 텍스트로 옮기면 깨집니다.
  응답을 base64로 넘기고 디코딩은 앱이 합니다.
- **콘텐트 스크립트는 URL 기준 주입** — 패널 iframe 이든 일반 탭이든 앱 주소면 붙습니다.

## Yahoo 는 확장으로 안 갑니다

Yahoo는 반대로 **가정용 IP를 `429`로 막습니다**(`Edge: Too Many Requests`).
그래서 앱이 Yahoo 요청만 클라우드 프록시로 보냅니다(`blocksResidentialIp`). 설정할 것은 없습니다.
