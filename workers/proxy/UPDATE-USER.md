# 내 전용 Cloudflare Worker 업데이트 가이드

이미 만들어 둔 Worker 를 **최신 코드로 바꾸는 방법**입니다. 처음 만드는 분은 [배포 가이드](DEPLOY-USER.md)를 보세요.

## 이럴 때 업데이트하세요

- 포트폴리오 화면 위에 **"⚠️ 내 프록시 업데이트 필요 — 다시 배포"** 가 보일 때
- 내 전용 프록시를 쓰는데 **내 종목 시세가 안 나오거나 늦게** 나올 때

> 왜 필요한가요? 토스가 **2026-11-12 저녁부터** 새 쿠키를 요구합니다. 그 전에 만든 Worker 는
> 이 쿠키를 넣지 않아 토스가 거절합니다(`invalid-client-state`). 지금은 앱이 공용 서버로 대신 받아
> 화면은 나오지만, 전용 프록시를 둔 의미(빠른 갱신·내 한도)가 없어집니다.

소요 시간: **약 2분**. 주소(URL)는 그대로라 포트폴리오 설정은 바꿀 필요가 없습니다.

---

## 1. 최신 코드 복사

새 탭에서 아래 주소를 엽니다 (**`.js` 파일**이어야 합니다).

```
https://raw.githubusercontent.com/hanjungwoo3/portfolio-web/main/workers/proxy/src/worker.js
```

화면에 코드만 길게 나옵니다. **Cmd+A**(윈도우 Ctrl+A) → **Cmd+C**(Ctrl+C)로 전부 복사합니다.

## 2. 내 Worker 코드 열기

1. [Cloudflare 대시보드](https://dash.cloudflare.com) 로그인
2. 왼쪽 메뉴 **Workers & Pages** → 내 Worker(예: `portfolio-proxy`) 클릭
3. 오른쪽 위 **Edit code** 클릭

## 3. 코드 바꿔 끼우기

1. 왼쪽 코드 영역을 한 번 클릭
2. **Cmd+A**(Ctrl+A)로 기존 코드 전체 선택 → **Delete**
3. **Cmd+V**(Ctrl+V)로 1번에서 복사한 코드 붙여넣기
4. 아래 상태줄이 **0 errors** 인지 확인 (에러가 보이면 1번 주소가 `.js` 인지 다시 확인)

## 4. 배포

오른쪽 위 파란 **Deploy** 버튼 → 5~10초 기다립니다.

> 오른쪽 미리보기에 `Error 1031` 이 떠도 화면 오류일 뿐 배포에는 영향이 없습니다.

## 5. 확인

포트폴리오 사이트를 **새로고침**합니다.

- 위의 **"⚠️ 내 프록시 업데이트 필요"** 가 사라지고 내 종목 시세가 나오면 끝입니다.
- 그래도 보이면 브라우저 캐시 때문일 수 있습니다 — 한 번 더 새로고침(Cmd+Shift+R / Ctrl+Shift+R) 해 보세요.

---

문제가 계속되면 [배포 가이드의 트러블슈팅](DEPLOY-USER.md#트러블슈팅)을 보거나, 크롬 확장·앱을 쓰면 프록시 없이 바로 받습니다.
