# 증권사·거래소 공식 API 연동 계획

작성 2026-10-24 · 갱신 2026-10-26(토스 먼저, PC 가져오기→Drive 동기화) · 상태: **기획(구현 전)** · 다음 할 일: 맨 아래 "다음에 할 일"

사용자가 자기 키를 넣으면 그 API 로 자료를 받고(계좌 자료 포함), 끄면 지금 소스로 돌아가는 기능.

## 1. 결론 요약

| 대상 | 개인 키 | 주는 것 | 판단 |
|---|---|---|---|
| **한국투자증권 (KIS Developers)** | APP KEY·SECRET + 계좌번호 | 계좌 + **장중 종목 수급·거래원·주식선물** 등 가장 넓음, 모의투자 계좌 있음 | **1순위** |

## 2. 공통 설계

### 2-1. 자동 대체 (켜면 공식 API, 끄면 원래대로)
- 설정에 증권사별 **"사용" 스위치**. 키를 넣으면 연결 시험 → 성공하면 켜짐.
- 켜져 있으면 바꿀 수 있는 자료(일봉·분봉·호가·수급 등)를 **공식 API 먼저**.
- 끄면 앱 재시작 없이 즉시 원래 소스(야후·네이버·토스 비공식).
- 켜져 있어도 공식 API 실패(403 허용 IP·한도 초과·종목 없음) → **그 요청만 원래 소스로** 대신 받음(화면이 비지 않게).
- 구현: 자료 받는 함수 앞에 **소스 선택 층** 하나. 화면 코드는 그대로. 두 소스 값 모양(단위·기준가·시각대)을 맞춰서 넘김.
- 기기 캐시(marketCache, 일봉 6시간)는 **소스별 키로 따로** 저장(섞지 않음).
- 상태 표시: 설정 "연결됨 · 최근 1분 요청 N · 실패 대체 N", 시세 소스 배지에 공식 API 사용 중 표시.

### 2-2. 계좌 자료는 자동 덮어쓰기 안 함
- 보유·이력·예수금은 원래 손으로 넣는 값 → **비교 화면 → "가져오기" 눌러야 반영**.
- 거래 이력은 기존 기록과 겹치는 건 빼고 넣기.
- 스위치를 꺼도 이미 가져온 기록은 남음.

### 2-3. 플랫폼
- 증권사 API 는 브라우저 직접 호출 불가(CORS) + 공용 중계로 남의 키 통과 금지 → **데스크톱 앱(Tauri) 네이티브 요청**.
- 토스는 **허용 IP 필수(CIDR 불가)** — 사용자 집 IP. 웹 중계 서버(CF·Deno 등)는 IP 가 바뀌어 원천 불가. 안드로이드는 와이파이일 때만.
- 한국투자증권 허용 IP 필요 여부: **미확인**.

## 2-4. PC 에서 가져와 저장 → 휴대폰은 Drive 동기화 (2026-10-26 결정)

| | PC 데스크톱 앱 | 휴대폰(APK·웹) |
|---|---|---|
| 증권사 키 | OS 비밀 보관함 | **없음** |
| 조회 | 거래 이력·보유·예수금 조회 → 비교 → "가져오기" | 안 함 |
| 저장 | **기존 앱 데이터 형식 그대로**(거래·보유·예수금) | — |
| 동기화 | Drive 로 올림 | Drive 에서 받음(기존 로직 그대로) |
| 시세 자동 대체 | 키 있으면 공식 API 먼저 | 기존 소스 |

- 증권사 기능은 **조회 위주**. 가져온 결과만 기존 데이터에 넣고, 휴대폰은 기존 구글 동기화로 받는다.
- 키·토큰은 Drive 동기화·파일 백업에서 **제외**(비밀 보관함에만).
- **새 필드 최소화** — Drive `normalize()` 에 없는 필드는 조용히 사라진다(entryPrice 사고). 주문번호 등 추가 필드가 꼭 필요하면 normalize + 재발방지 테스트 같이.
- (선택) "토스 기준 MM/DD HH:mm 가져옴" 메타만 동기화해 휴대폰에 표시 — 넣으면 normalize 반영.
- 가져오기 시점: 처음엔 PC 버튼 → 비교 → 가져오기. 나중에 "앱 켤 때 새 거래 자동 추가" 선택 옵션. 보유·예수금은 계속 확인 후 반영.
- 휴대폰 설정의 증권사 칸 = "PC 데스크톱 앱에서 연결합니다" 안내만.

## 2-5. 기존 '📥 토스 거래 가져오기'(내거래 탭, PC)와의 관계

- 지금: 토스 웹 로그인한 브라우저에서 `wts-api.tossinvest.com/api/v3/my-assets/transactions/markets/kr` 를 팝업으로 열고 JSON 을 **복사·붙여넣기** → 매수(5)·매도(6)만 → 중복 비교 → 체크 → 추가(id `toss_<키>`). 6개월·50건 단위, **국내만**.
- 바꿀 것: 데스크톱 앱 + 토스 키면 같은 대화창에 **"자동으로 불러오기"** — Open API `orders?status=CLOSED` 를 기간별로 받아 **같은 후보 목록**에 채움(중복·체크·그룹·추가 흐름 재사용). **미국 거래도**.
- 유지: 붙여넣기 방식은 그대로 둔다 — 웹 사용자, 그리고 Open API 가 안 주는 **장전·장후 시간외 종가 주문**용.
- 중복 판별: 지금 키 = 종목·날짜·매수/매도·수량·금액(원 반올림). Open API 는 체결수량·평균가 → 금액이 몇 원 다를 수 있음 → **금액은 0.1% 이내면 같은 거래**로. 분할 체결(체결별 vs 주문 단위)은 실제 응답 비교 후 결정.

## 2-6. 자동 연동 값은 수동 값과 따로 (2026-10-26 결정)

이미 손으로 넣은 토스 종목·거래가 있을 수 있다 → 섞지 않는다.

1. **보유 종목** → 전용 그룹 **"🔗 토스(연동)"**
   - 연동 보유는 이 그룹에만. 수동 그룹(예: "0. 토스")은 **건드리지 않음**.
   - 이 그룹 = 토스 계좌의 **거울**: 가져올 때마다 그룹 안을 토스 값으로 통째로 교체(확인 절차 불필요). 대신 **손으로 수정 안 하는 그룹** — 화면에 수정 버튼 대신 "토스 기준 MM/DD HH:mm".
   - 기존 '그룹(account)' 필드 그대로 → 새 필드 없음 → Drive 동기화로 휴대폰에 그대로.
2. **거래 내역** → 그룹 "🔗 토스(연동)", id 앞머리 **`tossapi_`**(재가져오기 = 덮어쓰기, 멱등)
   - 수동 거래·붙여넣기 거래(`toss_`)는 그대로.
   - 수동 기록과 같아 보이면 지우거나 합치지 않고 **"수동 기록과 겹치는 것 같음"** 표시만. 정리는 사용자가.
3. **합계 이중 계산 방지**
   - 처음 연결할 때 비슷한 수동 그룹을 찾아 "합계에서 뺄까요 / 그대로 / 나중에 지울까요" 물음. 삭제는 사용자가 직접 할 때만.
   - 연동 그룹 ↔ 수동 그룹 **나란히 비교**(수량·평단 차이) 화면 — 수동 값 검증용으로도.
4. **예수금** → 연동 그룹 예수금으로 따로. 수동 예수금과 섞지 않음.

※ 2-4 의 "보유·예수금은 확인 후 반영"은 이 결정으로 바뀜 — 연동 그룹은 거울이라 바로 교체, 수동 그룹은 손대지 않음.

## 3. 개인정보·보안

### 저장
| 정보 | 위치 | 밖으로 |
|---|---|---|
| 증권사 키·계좌번호 | **OS 비밀 보관함만** — 맥 키체인 / 윈도우 자격 증명 관리자(DPAPI) / 안드로이드 Keystore | 안 나감. Drive 동기화·파일 백업·로그 제외 |
| 접근 토큰(24h) | 앱 메모리 + 비밀 보관함 | 증권사로만 |
| 가져온 보유·이력 | 지금 앱 데이터와 같은 곳(IndexedDB) | 사용자가 켠 경우만 본인 Drive 숨김 공간 |

- 비밀키는 화면에 다시 안 보여 줌(●●●● + "바꾸기"). **웹 코드가 키를 못 읽게** — Rust(네이티브)만 꺼내서 붙임.
- 비밀 보관함 자체가 OS 암호화. 앱이 한 겹 더 씌우는 건 키를 앱에 둬야 해서 효과 없음.
- **보유·거래 기록은 지금도 평문**(IndexedDB). 더 강하게 하려면 **앱 잠금 암호(선택 기능, 별도 단계)** — 사용자 암호로 AES-GCM. 단점: 매번 입력, **잊으면 복구 불가**. 증권사 연동과 묶지 않음.
- privacy.html 에 "증권사 연동(선택)" 항목 + "기록은 기기에 평문 · 디스크 암호화(FileVault·BitLocker) 권장" 사실대로.

### 요청
- 사용자 컴퓨터 → **증권사로 직접**. 공용·개인 프록시·운영자 서버 안 거침.
- 네이티브 **허용 주소 목록**: 키는 정해진 호스트의 조회 주소에만 붙임
  (토스 `openapi.tossinvest.com`, 한국투자 `openapi.koreainvestment.com`(실전) / 모의투자 별도 주소).

### 주문 금지
- 두 증권사 모두 **그 키로 실주문 가능**(읽기 전용 키 없음).
- 네이티브에서 **조회만 허용**: 토스 = GET 만, 한국투자 = 조회용 tr_id 만. 주문·정정·취소는 네이티브가 거절 → 웹 코드가 바뀌어도 주문은 못 나감.

### 연결 해제
- 설정 "연결 해제" → 비밀 보관함 키·토큰 삭제, 가져온 기록 남길지 선택.
- 증권사에서 키 폐기 안내(토스 WTS 설정 > Open API, KIS Developers).
- 안내 문구: "키는 이 컴퓨터에만 · 조회만 · 주문 불가", 안 쓸 땐 키 끄기 권장, 한국투자는 모의투자로 먼저 시험 권장.

## 4. 토스증권 Open API

- 문서: developers.tossinvest.com/llms.txt · openapi.tossinvest.com/openapi-docs/latest/openapi.json
- 실측 함정(2026-09-09): 경로는 **`/api/v1/`**, 토큰은 **HTTP Basic**(`-u id:secret -d grant_type=client_credentials`), 24h.
- **클라이언트당 유효 토큰 1개** — 새로 받으면 직전 토큰 즉시 무효(`401 token-revoked`). 같은 키를 다른 프로그램에서 쓰면 서로 끊음 → 토큰 저장해 24h 재사용, "다른 곳에서 쓰는 키면 따로 발급" 안내.
- 한도: 초당 — MARKET_DATA 15/s, CHART 20/s, ACCOUNT 1/s.
- 계좌 헤더 `X-Tossinvest-Account`(= `/api/v1/accounts` 의 accountSeq).

### 계좌
`accounts` · `holdings`(국내·미국 수량·평단) · `orders?status=CLOSED`(기간 from~to, 최대 100건 커서. **지정가·시장가·장마감지정가만 — 장전·장후 시간외 종가 주문은 빠짐**) · `orders/{id}` · `buying-power`(**예수금 자동**) · `commissions` · `conditional-orders` · `sellable-quantity`

### 시세·정보 (대체 가능)
| 지금 | 지금 소스 | 토스 API |
|---|---|---|
| 일봉(3개월·1년, ETF 구성·검색, 섹터 순위) | 야후(**429 차단 겪음**) | `candles` 1d, 200봉·이어받기, 수정주가 |
| 분봉(카드 24시간) | 토스 비공식 c-chart·야후 spark | `candles` 1m (미국 프리·애프터 포함 여부 미확인) |
| 현재가 | 토스 비공식·야후 | `prices`(200종목, lastPrice 만 → 등락률은 `rankings`) |
| 호가·체결 | 토스 비공식 | `orderbook` · `trades`(50) + 웹소켓 |
| 종목 투자자 매매(일별) | 네이버 60일·3분류 | `stocks/{s}/investor-trading` 100일 |
| 프로그램·공매도·대차 | 토스 비공식 | 공식 각각 |
| 코스피·코스닥 | 야후·토스 비공식 | `market-indicators`(국내 지수·국채 8종) |
| 환율·장 운영·투자주의·섹터 | 야후·비공식 | `exchange-rate`·`market-calendar`·`warnings`·`sectors` |

### 새로 가능
신용거래 동향 `credit-trades` · 상·하한가 `price-limits` · 시장 투자자 매매대금 **주·월·연** 집계(KRX 로그인 때문에 못 하던 것) · 섹터별 관련 ETF(공식) · **내 주문 체결 실시간 알림**(웹소켓)

### 없음(대체 불가)
뉴스·공시·커뮤니티 · ETF 구성 · 선물·옵션 · 해외 지수·VIX·원자재 · 거래원 · 컨센서스·재무 · **시간별 시장 투자자 수급**(일·주·월·연만)

## 5. 한국투자증권 (KIS Developers)

- 공식 예제: github.com/koreainvestment/open-trading-api (`examples_llm/`)
- 토큰 24h, **1분에 1번만 발급**(EGW00133), 6시간 안 재요청은 같은 토큰 → 반드시 저장해 재사용.
- API 마다 `tr_id` 다름, **실전/모의 서버·tr_id 따로**. **모의투자 계좌로 실제 돈 없이 시험 가능**.
- 한 번에 여러 종목 받는 API 가 적음(종목별) → 보이는 종목만.

### 계좌
국내 `inquire-balance` · `inquire-balance-rlz-pl` · **`inquire-daily-ccld`**(일별 주문체결, 3개월 이내/이전 구분 조회) · `inquire-psbl-order`(매수가능=예수금) · `inquire-period-trade-profit` · `inquire-period-profit` / 해외 `inquire-balance` · `inquire-present-balance` · `inquire-ccnl` · `inquire-period-profit`

### 종목별 수급 (토스보다 넓음)
| 정보 | API | 지금 |
|---|---|---|
| **장중 외국인·기관 추정** | `investor-trend-estimate` (MTS 투자자동향 '추정(주)'. 외국인 09:30·11:20·13:20·14:30 / 기관 10:00·11:20·13:20·14:30) | 토스 KRX 잠정치 한 줄 |
| 종목 투자자 매매(일별) | `investor-trade-by-stock-daily` | 네이버 60일·3분류 |
| **외국계 매매 종목 집계** | `frgnmem-trade-estimate` · `frgnmem_trade_trend` · `frgnmem_pchs_trend` | 없음 |

## 6. KRX Open API

- openapi.krx.co.kr · **무료** · 키 발급 + **API 마다 신청·승인**(보통 하루 안) · **1년마다 재신청**
- 키당 **하루 10,000번** · **전일치**(다음 영업일 08:00 갱신) · 실시간 없음
- 약관(2차 자료 인용, 원문 확인 필요): **비상업적, 제3자 제공 금지** → 운영자 키 공유 불가, **사용자 각자 키**
- 유료 실시간·대량 과거는 별도(KRX Data Marketplace) — 이 Open API 와 다름
- 분류: 지수 · 주식(**전 종목 일별 한 번에**, 기본정보) · 증권상품(ETF·ETN·ELW) · 채권 · 파생(선물·옵션 일별, 주식선물 포함 추정) · 일반상품(금·석유·배출권) · ESG
- 쓸 곳: 종목 찾기·기업가치 표 일괄, 주식선물 일별, ETF 순자산가치·괴리율, 금 현물·배출권 카드
- **판단 보류**: 사용자 부담 큼(승인·1년 재신청) + 일별은 지금 소스로도 대부분 됨. 단 **'투자자별 매매 실적'이 Open API 에 있으면 가치 큼**(예전에 KRX 로그인 때문에 포기) → 키 받아 승인 목록 확인 후 결정.
- 웹에서도 쓸 수 있는지는 KRX 서버 CORS 확인 필요.

## 7. MTS 정보에 대해
- MTS 가 더 많은 건 증권사 **내부 전용 API** 라서. 출처: 거래소 시세를 증권사가 가공(체결강도·거래원 등) / 유료 계약 데이터(컨센서스·리포트) / 자체 콘텐츠 / 로그인 계좌.
- 우리 앱도 이미 토스 WTS 내부 주소(wts-info-api·wts-cert-api)를 씀 — 예고 없이 바뀜(2026-10-22 `_browserId` 쿠키 요구로 확장·개인 프록시 막힘).
- **로그인 세션(아이디·비번·인증서)·유료 데이터는 가져오지 않음**. 계좌는 공식 키만. 공개 시세성은 지금처럼 + 공식 API 가 있으면 그쪽 먼저.

## 8. 만드는 순서(제안)

1. **공통 틀** — 키 저장(OS 비밀 보관함), 조회 전용 막기(네이티브), 허용 주소 목록, 스위치·자동 대체 층, 상태 표시. 데스크톱 앱 0.1.5.
2. **한국투자증권 연결** — 모의투자 키로 연결 시험 → 장중 추정 수급·주식선물을 종목정보 팝업에.
3. 계좌: 보유·예수금 **비교 → 가져오기**.
4. 거래 이력 가져오기(중복 제외).
5. 토스 연결(같은 틀) — 일봉 대체로 야후 차단 해결 등.
6. 나머지 시세 대체 + 신용잔고 등 새 정보, 체결 알림(웹소켓).
7. KRX — 키 승인 목록 보고 결정.
별도 선택 기능: 앱 잠금 암호(보유·기록 암호화).
