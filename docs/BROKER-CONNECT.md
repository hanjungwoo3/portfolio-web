# 증권사 연결 방법 (토스증권 · 한국투자증권)

내 증권 계좌를 연결하면 **보유 종목·예수금·거래 내역이 자동으로 들어오고**, 증권사만 주는 시세 정보도 더 볼 수 있습니다.

- **조회만 합니다.** 앱은 증권사에 "보여 달라"는 요청(GET)만 보냅니다. 주문·정정·취소 기능은 아예 들어 있지 않습니다.
- **키는 내 PC에만 저장됩니다.** 맥은 키체인, 윈도우는 자격 증명 관리자에 저장되고, 서버나 Google Drive로 올라가지 않습니다.
- **연결은 데스크톱 앱(맥·윈도우)에서만 됩니다.** 웹 브라우저·휴대폰에서는 키를 안전하게 둘 곳이 없어서 연결할 수 없습니다. 대신 PC 앱에서 받아 온 보유·예수금은 Google Drive 동기화로 휴대폰·웹에도 보입니다.

---

## 0. 준비

1. **데스크톱 앱 설치** — [앱 받기 (맥·윈도우)](https://github.com/hanjungwoo3/portfolio-web/releases/tag/apps)
   - 맥: `portfolio-mac.zip` / 윈도우: `portfolio-setup.exe`
   - 새 버전은 앱 안에서 업데이트 알림이 뜹니다.
2. **그룹별 독립 보유 모드 켜기** — 앱 `설정 → ⚙️ 일반 → 그룹별 독립 보유 모드`
   - 꺼져 있으면 같은 종목이 모든 그룹에서 같은 값으로 맞춰져서, 증권사에서 가져온 수량이 손으로 관리하는 그룹까지 덮어씁니다.

---

## 1. 토스증권 연결

### 1-1. 토스에서 키 받기
1. PC 웹브라우저로 [토스증권 웹(WTS)](https://www.tossinvest.com) 에 로그인합니다.
2. `설정 → Open API` 에서 키를 발급합니다. → **client_id**, **client_secret**
3. 같은 화면의 **허용 IP** 에 지금 이 PC의 공인 IP를 등록합니다.
   - 공인 IP는 네이버에서 "내 아이피"로 검색하면 나옵니다.
   - 집·회사·VPN을 바꾸면 IP가 달라져서 403 오류가 납니다. 그때 다시 등록하세요.

### 1-2. 앱에 넣기
1. 앱 `설정 → 🔗 증권사 연결 → 토스증권 Open API`
2. client_id·client_secret을 붙여 넣고 **저장하고 연결 시험**을 누릅니다.
3. 계좌가 보이면 연결 성공입니다.
4. **연동 그룹** 이름(예: `토스`)을 정하고 **연동 시작**을 누릅니다.
   - 토스 보유 종목이 이 그룹에 들어오고, 지수 탭 옆 `📁 증권사연결` 폴더에 놓입니다.
   - 5분마다 자동으로 갱신됩니다(**지금 갱신** 버튼도 있습니다).

### 1-3. 주의
- **이 앱 전용 키를 따로 발급하세요.** 토스는 키 하나에 토큰이 하나만 살아 있어서, 같은 키를 다른 프로그램과 나눠 쓰면 서로 연결을 끊습니다.
- 안 쓸 때는 토스 쪽에서 키를 끄거나 폐기하는 게 가장 안전합니다. 앱의 **연결 해제**는 이 PC에 저장된 키만 지웁니다.

## 2. 한국투자증권 연결

### 2-1. 한국투자에서 키 받기
1. [KIS Developers](https://apiportal.koreainvestment.com) 에 한국투자증권 계정으로 로그인합니다.
2. **API 신청**에서 사용할 계좌를 고르고 신청하면 **앱키(appkey)·앱시크릿(appsecret)** 이 나옵니다.
   - **실전 키와 모의투자 키가 다릅니다.** 모의투자로 먼저 해 보려면 모의투자 계좌를 따로 신청하고 모의 키를 받으세요.
   - 허용 IP 등록은 필요 없습니다.

### 2-2. 앱에 넣기
1. 앱 `설정 → 🔗 증권사 연결 → 한국투자증권 Open API`
2. **구분**(실전/모의)을 고르고 **종합계좌번호 8자리**와 상품코드(보통 `01`)를 넣습니다.
3. 앱키·앱시크릿을 붙여 넣고 **저장하고 연결 시험**을 누릅니다.
   - "연결됐습니다 — 보유 N종목 · 예수금 …원"이 나오면 성공입니다.
4. **연동 사용**을 켜고, **연동 그룹 이름**을 정한 뒤 **연동 시작**을 누릅니다.

### 2-3. 연결하면 더 보이는 것 (앱에서만)
| 위치 | 내용 |
|------|------|
| 📊 종목정보 창 — 체결 칸 | **실시간 체결** — 체결이 나는 즉시 들어옵니다(제목 옆 `● 한투 실시간`). 끊기면 자동으로 토스 5초 갱신으로 넘어갑니다. |
| 📊 종목정보 창 — 선물 칸 | 주식선물이 있는 201개 종목의 **근월물 시세·베이시스·미결제약정·1분봉** |
| 📊 종목정보 창 — 프로그램·투자자 칸 | **장중 외국인·기관 추정 순매수**(증권사 가집계, 하루 몇 차례) |
| 📊 종목정보 창 — 상단 | 오늘 **VI 발동** 내역(있을 때만) |
| 지수 탭 — 반도체 수급 옵션 칸 | 코스피200 **옵션 근월물 전 행사가** 콜·풋 거래량·미결제약정 |
| 지수 탭 — 맨 위 | **동시호가 예상 등락률 순위**(평일 08:25~09:03, 15:15~15:33에만 나타남) |

### 2-4. 주의
- 한국투자 토큰은 **1분에 한 번만** 새로 받을 수 있습니다. 연결 직후 오류가 나면 1분 뒤 다시 시도하세요(앱은 받은 토큰을 24시간 재사용합니다).
- 모의투자 키는 초당 요청 수가 적어서 화면이 늦게 채워질 수 있습니다.

## 3. 자주 묻는 것

**Q. 웹이나 휴대폰에서도 보이나요?**
보유·예수금·거래는 PC 앱이 받아 Google Drive 동기화로 올리므로 다른 기기에서도 보입니다. 실시간 체결·선물·동시호가 순위처럼 증권사에 직접 물어봐야 하는 정보는 PC 앱에서만 보입니다.

**Q. 키가 새어 나갈 위험은?**
키는 PC의 비밀 보관함에만 있고, 웹 화면 코드는 키를 읽을 수 없습니다. 앱(네이티브)이 키를 꺼내 증권사에 직접 요청하고, 결과만 화면에 넘깁니다. 실시간 체결용 접속키도 앱 안에만 둡니다.

**Q. 맥에서 "키체인 접근 허용" 창이 떠요.**
앱을 업데이트한 뒤 처음 한 번 뜹니다. **허용**(또는 항상 허용)을 누르세요.

**Q. 연결을 끊으려면?**
앱 `설정 → 🔗 증권사 연결`에서 **연동 그룹 해제**(보유는 남고 잠금만 풀림) 또는 **연결 해제**(이 PC의 키 삭제)를 누르세요. 증권사 쪽 키 폐기는 각 증권사 사이트에서 따로 합니다.
